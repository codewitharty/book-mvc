# Pro PHP 8 MVC — 2nd Edition

This repository documents my journey through **Pro PHP 8 MVC, 2nd Edition**.

## The Motivation

I began learning PHP using Laravel, but I quickly realized that while the framework is brilliant, I was often relying on it without fully grasping the underlying mechanics. Concepts like routing, HTTP requests/responses, error handling, and the core principles of MVC started feeling like black boxes rather than understood logic.

Therefore, this project serves as a deliberate step back to master these fundamentals by building a simple MVC application using **plain PHP 8**. The goal is not just to build an app; it's to understand *what* happens underneath the framework when you call `Route::get('/users', ...)` or handle an exception.

## What I Am Learning

As I work through the book, I am focusing on mastering core concepts such as:
*   PHP 8 fundamentals and syntax.
*   HTTP requests and responses lifecycle.
*   The mechanics of Routing.
*   Robust Error and Exception Handling.
*   Implementing the MVC architecture (Controllers, Models, Views).
*   Database interaction and Sessions management.

## My Philosophy: Understand First, Build Second.

The code here might look simple at first—that is intentional. I am prioritizing understanding each piece before hiding it behind a framework's abstraction layer. By the end of this journey, my goal is to have an intuitive grasp of *why* MVC exists and *how* PHP executes it, rather than just knowing *what* syntax to use.

**Current Focus:** Currently diving deep into implementing the core MVC structure, focusing heavily on Controllers and Models integration.
